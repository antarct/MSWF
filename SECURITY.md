# Security Policy

## Supported Versions
Only the latest release of Fumé Emerald is actively maintained and supported with security and stability updates.

| Version | Supported          |
| ------- | ------------------ |
| v2.5+   | :white_check_mark: |
| < v2.5  | :x:                |

## Reporting a Vulnerability
If you discover a potential security vulnerability, memory leak, or unauthorized data access issue:
1. Please do **not** open a public issue.
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/antarct/MSWF/security/advisories) or contact the maintainer directly.
3. Include detailed steps to reproduce the issue and your device hardware specifications.
